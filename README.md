# CATEKIDS · Calendario de asistencias para GitHub Pages

La asistencia del sábado cuenta para la obligación del domingo siguiente. Entrada y salida cuentan una vez. Una obligación actual queda `Pendiente` hasta que termine el día. El calendario muestra misa dominical, Hora Santa y misa solemne.

## Publicación

1. En Google Sheets abre **Extensiones → Apps Script** y reemplaza `Code.gs` con este archivo.
2. Implementa como **Aplicación web**, ejecutada como tú y accesible para **Cualquier persona**.
3. Copia la URL terminada en `/exec`.
4. En `docs/index.html`, reemplaza `PEGA_AQUI_LA_URL_DE_APPS_SCRIPT` por esa URL.
5. Sube la carpeta al repositorio de GitHub.
6. En **Settings → Pages**, selecciona la rama `main` y la carpeta `/docs`.
7. Abre GitHub Pages en Chrome y concede permiso de cámara.

Prueba: `Conf4Jesus Alejandro Alcocer Torres` debe reconocer el registro del sábado 05/09/2026 como asistencia del domingo 06/09/2026.
